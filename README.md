# Flores amarillas

Abre esta carpeta desde Visual Studio Code: Archivo > Abrir carpeta.
Abre index.html en tu navegador para ver la página.

- index.html: estructura, textos e imágenes.
- styles.css: colores, tamaños y animaciones CSS.
- animaciones.js: efectos animados y música.
- carta-girasoles.js: carta, carrusel y dibujo de girasoles.

Se conserva el orden de carga del JavaScript original. Las imágenes, música, fuentes y librerías externas requieren Internet.
Para GitHub, sube los cuatro archivos de código juntos a la raíz del repositorio.
